마크다운은 단순하지만, 잘 쓰면 읽기 좋은 글이 됩니다.

## 강조와 목록

- **굵게** 쓰면 핵심이 드러납니다.
- *기울임*은 살짝 강조할 때 씁니다.
- `인라인 코드`는 짧은 명령어에 적합합니다.

## 코드 블록

```js
const greeting = "hello, blog";
console.log(greeting);
```

## 인용

> 좋은 글은 복잡한 도구보다, 꾸준한 기록에서 나옵니다.

카테고리와 태그를 달아 두면 사이트에서 같은 주제끼리 모아 볼 수 있습니다.
